# Glossary

- **SKU (Stock Keeping Unit):** A specific item tracked in inventory. In this app, it usually refers to Raw Ingredients (e.g., "Egg White Raw").
- **Outlet:** A specific cloud kitchen or store location (e.g., "BLR Row Hsr Layout").
- **Brand:** The consumer-facing restaurant brand (e.g., "Nomad Pizza", "EatFit").
- **POS (Point of Sale):** The system where customer orders are placed. Specifically refers to UrbanPiper data in this app.
- **Dish Sales:** Finished goods sold to end consumers (tracked via UrbanPiper).
- **Kitchen Consumption:** Raw ingredients used in the kitchen to prepare dishes (tracked via SupplyNote).
- **Variance:** The difference between theoretical consumption (what recipes dictate should have been used based on Dish Sales) and actual consumption (what SupplyNote says was actually used).
- **WMAPE (Weighted Mean Absolute Percentage Error):** A statistical metric used to measure the accuracy of the forecasting engine.
- **JWT (JSON Web Token):** The secure token generated by Supabase used to verify a user's identity across the frontend and backend.
